Ask the grain lakehouse.

An AI analyst that answers from Grainflow's corn, soybean and wheat data. It shows the SQL behind every number, and it can't change anything.

Use it from your own tools

Silo is an MCP server, so any MCP client can query the same lake with the same guardrails. Point it at this endpoint:

/mcp

Tools: list_tables, describe_table, list_metrics, query_metric, run_query and data_freshness. All read-only.

Why you can trust the numbers

  • Named metrics first. Ratings must pick a crop and stay in USDA's 18 states; prices must pick a contract.
  • Two locks on SQL. A parser allows one read-only SELECT, and the engine itself can't read files or the network.
  • Tested on every change. 13 questions with answers computed from the data must pass before a PR merges.
  • Bounded cost. Example answers are cached daily; free questions share a small daily budget.
